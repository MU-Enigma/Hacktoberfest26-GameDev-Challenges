# 🎮 Level 1 — Movement Basics

## Objective

Implement a **2D player controller** where the character can move using **WASD** or **Arrow keys**.

## Recommended Assets

- **Blue Chicken** from the provided Resources folder
- Or any 2D sprite of your choice

## Tasks

1. Create a **2D project** in Unity.
2. Create a **Player GameObject** and add a movement script.
3. Implement movement using **WASD / Arrow keys**.
4. Test your player movement.
5. Add your project to your **personal folder** in the repository.

## Resources

A basic player movement tutorial is available in the **Resources** folder.

You can use the provided tutorial and assets to complete the task.

## Submission

- Add your Submission to your **personal folder** in the repository.
