# Level 2: Character Mechanics - Duck Game

A 2D character mechanics game built with Unity for Hacktoberfest 2026 GameDev Challenges (Level 2).

## 🎮 Controls & Abilities

Here is the list of abilities and controls implemented for the duck:

- **WASD / Arrow Keys**: Move around
- **Space**: Play quack sound effect
- **Q**: Spawn Abhinav (the obstacle)
- **E**: Spawn egg
- **X**: Disappear for 2 seconds (invisibility cloak)
- **I**: Teleport back to initial position (center)

## 🚀 How to Run

1. Open **Unity Hub** and add the project located in `GD_Level_2`.
2. Open the scene at `Assets/Scenes/duck_poo.unity`.
3. Press the **Play** button in Unity Editor and experiment with all the abilities!
