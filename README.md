# 🎮 Game Development

Welcome to the Game Development repository by Sandbox!

This repository is created for Hacktoberfest contributions and is focused on beginner-friendly game development projects.

Most of the projects and tasks in this repository are created using **Unity**, so having Unity installed is recommended. however you are free to use any game engine of your choice!

## 🛠️ Installing Unity

### Step 1: Download Unity Hub

Unity Hub is used to install and manage Unity Editor versions.

Download Unity Hub from:

https://unity.com/download

### Step 2: Install Unity Editor

After installing Unity Hub:

1. Open **Unity Hub**
2. Sign in or create a Unity account
3. Go to the **Installs** tab
4. Install a Unity Editor version
5. Install any required modules based on your needs

### Video Tutorial

For a step-by-step guide on downloading and installing Unity, follow this tutorial:

https://youtu.be/X-NSBNbaQhs?si=2NMa4O4iaC7WFLMi

## 🎮 Using Other Game Engines

You are free to use any game engine you are comfortable with.

If you choose to use another engine, make sure to:

- Add the appropriate `.gitignore` file for that engine, this repo already has a `.gitignore` which tracks unity projects ONLY.
- Avoid committing unnecessary generated files.
- Keep your project structure clean and organized.

Make sure to use the correct `.gitignore` file for your engine before creating a Pull Request

## Level 1: Basic Character Movement

Implement basic character movement.

You can use the blue_chicken.png from the **Resources** folder provided in this repository for the charatcer sprite

A movement tutorial is also available inside the **Resources** folder to help you get started.

## Level 2: Character Mechanics

Now that your character can move, it's time to make it more interesting!

Create a **new project** and add unique mechanics and interactions to your character.

Some examples:

- Dash ability
- Sprinting
- Teleportation
- Double jump
- Special abilities
- Random interactions

You can also add keyboard interactions.

Example:

Pressing **"E"** could make your character:

- Spawn a burger 🍔
- Summon a random object
- Change size
- Activate a funny ability
- Interact with the environment

The possibilities are endless.

Try to be as creative and absurd as possible. The more unique your mechanic is, the better!

## Level 3: Level Design

Now take your character and mechanics and create a proper playable level.

Create basic platformer levels where your character can use the abilities you created.

Your level can include:

- Platforms
- Obstacles
- Challenges

This 5 mins tutorial explains the basics of making a level in Unity very quickly.

https://www.youtube.com/watch?v=E25JWfeCFPA&t=77s

You can also take inspiration from existing games and design your own versions of levels.

Some games you can take inspiration from:

- **Die Again**

Have fun experimenting and creating, make as many levels as you can!
